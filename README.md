# kbbs

카카오톡을 하이텔처럼 쓰는 macOS 터미널.

```bash
brew install gum798/kbbs/kbbs
kbbs
```

첫 실행 때 **손쉬운 사용 권한**을 요청합니다. 시스템 설정 > 개인정보 보호 및 보안 >
손쉬운 사용에서 켜 주세요. 카카오톡이 실행되어 있어야 합니다.

권한 없이 화면만 보려면 `kbbs --demo`.

## 키

**목록** — `↑↓` 이동, 숫자 + `Enter` 로 입장, `P`/`N` 쪽 넘김, `R` 새로고침,
`W` 창 닫기, `Q` 종료.

**대화방** — `Enter` 전송, `⌥Enter` 줄바꿈, `Esc` 목록, `S` 카카오톡에서 창 보기,
`W` 창 닫기.

**한글 입력 상태**에서는 자모가 바로 오지 않습니다 — 입력기가 글자 하나를 완성해야
넘겨주기 때문에, `ㅉ` 만 누르면 그 순간엔 아무 일도 안 나고 다음 키를 누를 때 뒤늦게
딸려 옵니다. 그래서 같은 명령이 `Ctrl` 조합으로도 있습니다: `Ctrl-W` 창 닫기,
`Ctrl-R` 새로고침, `Ctrl-N`/`Ctrl-P` 쪽 넘김, `Ctrl-Q` 종료. 이쪽은 누른 그 순간에
동작합니다.

`*` 는 카카오톡에 창이 열린 방입니다. `-` 인 방은 들어갈 때 카카오톡이 잠깐 앞으로
나와 목록의 해당 줄을 대신 눌러 줍니다 — 그 전에 물어봅니다.

## 안 하는 것

이미지·파일 전송, 검색, 스크롤백, 알림, 로그인. **암호는 입력하지 않습니다** — 여러 번
틀리면 카카오톡이 계정을 로그아웃시키기 때문이고, 그럴 코드가 바이너리에 없습니다.

## 주의

Kakao Corp. 의 공식 도구가 아니며 제휴·보증 관계가 없습니다. macOS 손쉬운 사용 API 로
화면에 떠 있는 카카오톡을 조작하며, 비공개 LOCO 프로토콜은 건드리지 않습니다. 자동화
도구 사용으로 생길 수 있는 계정 제한·오작동·데이터 손실의 책임은 사용자에게 있습니다.
